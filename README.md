# sines-

A Python project that visualizes three sinusoidal curves using NumPy and Matplotlib.

The project displays:
- `y1 = sin(x)`
- `y2 = sin(2x)`
- `y_total = sin(x) + sin(2x)`

It uses NumPy for numerical calculations and Matplotlib for plotting.

## Installation

Install the required libraries:

pip install -r requirements.txt


## Run

python main.py
